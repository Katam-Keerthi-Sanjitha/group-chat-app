# Centralized Group Chat Application

A real-time web-based group communication platform built with React, Node.js, Express, Socket.IO, and SQLite.

## Features
- User Registration and JWT Authentication
- Create and Join Groups via 6-character Invite Codes
- Real-Time Group Messaging via WebSockets
- File and Image Sharing
- Role-Based Access Control (Group Admin & Members)

## How to Run Locally

### 1. Start Backend Server
\ash
cd server
npm install
node index.js
\\n
### 2. Start Frontend Client
\ash
